# Evaluation — v3 (quantile gradient boosting)

All numbers below are read from `artifacts/v3/dev/development/metrics.json`,
`artifacts/v3/dev/development/qgb_search.json` and `artifacts/v3/metrics.json`
(generated by `python -m forecast_bust.evaluate_qgb`). Nothing is hand-entered.

Three different claims are kept apart:

* **Works as engineering** — trains in 72–109 s at 2.5 GB peak RSS on the 8 GB machine, serves in ~0.2 s
  per case, quantiles valid and ordered, probabilities in [0, 1], tests pass. **Yes.**
* **Works scientifically** — near-nominal quantile coverage, calibrated probabilities (ECE ≤ 0.013),
  discrimination clearly above climatology (AUPRC ≈ 1.6× the base rate). **Yes, with a weak signal:**
  ROC AUC ≈ 0.63, Brier only ~2% better than climatology.
* **Outperforms baselines** — above B0 climatology: **yes**. Above the spread-only B2 classifier: **no**.
  On the only controlled comparison (dev split, same rows), v3 is significantly *below* B2
  (−0.018 AUPRC, CI excludes 0). The single input `spread_thr_ratio` alone ranks busts better than v3's
  probability (dev-test AUPRC 0.163 vs 0.143). v3 was kept as the production model by the project
  decision to retire B2, not because it beats it.

## 3. What improved and what did not

* Improved (vs v2's product): a continuous error *distribution* per region-day (central error, range,
  upper tail) with near-nominal coverage; well-calibrated probability (2022 ECE 0.0045); non-zero
  hidden-bust recall (0.075 vs v2 B2's 0.000 at their operating points); a model that trains comfortably
  on the development machine, unlike QRF.
* Not improved: bust discrimination relative to a spread-only classifier. Hidden busts remain largely
  undetected (recall 0.075). Peak-risk-day and spatial-overlap skill remain low.
